# Lang

Support the optional `lang` parameter, per `contract-protocol.md` (Connection)
and `architecture.md` (Providers).

- Read `lang` from the connection URL. A well-formed tag is passed to the
  provider. A malformed one is logged as a warning, quoted with `quoteForLog`,
  and not passed on.
- Mistral: send the language code in `session.update` when it has two letters.
  Otherwise send no language.
- Deepgram: send the tag as `language`. When Deepgram refuses a tag that has
  subtags with HTTP 400, open again with its language code. A second refusal
  fails the open.
- Tests for the server, both providers and the Deepgram fallback. The Deepgram
  live test uses `lang=en-XY`, which Deepgram refuses, to check the fallback to
  `en` against the real API.
