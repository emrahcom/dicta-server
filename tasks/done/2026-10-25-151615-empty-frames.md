# Empty frames

Ignore empty binary frames, per `contract-protocol.md` (Client to server).

- Server: an empty binary frame is not sent to the provider and does not count
  as audio, so it neither starts the 5 second timer nor makes the next finish
  ask the provider.
- Tests: an empty binary frame followed by `end` gives an empty final without
  asking the provider, and the provider gets no empty chunk.
