# Serve dicta-js

Serve the built `dicta-js` under `/dicta/js/`, per `architecture.md` (dicta-js
files, Health).

- At startup, the server reads every `.js` file in `js/` and its subfolders, if
  the folder exists, into memory, with an `ETag` from a hash of its content.
  `createServer` takes the folder, so tests can use a temporary one; `index.ts`
  passes `js/` in the server's root.
- `GET` and `HEAD` on `/dicta/js/<path>` answer a loaded file with
  `content-type: text/javascript`, `cache-control: no-cache`, its `ETag` and
  `access-control-allow-origin: *`. A request whose `If-None-Match` matches the
  `ETag` gets `304` without a body. Anything else gets `404`. Nothing is logged.
- `js/` is added to `.gitignore`.
- Docs: `docs/deployment.md` explains `/dicta/js/index.js` and the `js/` folder.
- Tests: with a temporary folder, a file and a file in a subfolder are served
  with the headers, `If-None-Match` gets `304`, `HEAD` has no body, and an
  unknown file, a non-`.js` file, a path with `..` and `POST` get `404`. Without
  the folder, `/dicta/js/index.js` gets `404`.
