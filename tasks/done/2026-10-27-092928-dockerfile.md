# Dockerfile

Add a `Dockerfile` that builds the server image, per `architecture.md` (Docker
image, dicta-js files).

- Build argument `DICTA_JS_VERSION`, required. The first stage gets the
  `dicta-js` source of that tag from GitHub and runs `npm ci` and
  `npm run build`.
- The final stage has `package.json`, `package-lock.json`, the production
  dependencies (`npm ci --omit=dev`), `src/` and the built `dist/` as `js/`. It
  has the label `dicta-js.version`, runs as `node` with `node src/index.ts` and
  exposes `8080`.
- A `.dockerignore` keeps `node_modules`, `js/`, git, tests, specs, tasks and
  docs out of the build context.
- Docs: `docs/deployment.md` explains how to build and run the image.
- Check: build the image locally, run it with `PROVIDER=stub` and
  `ALLOW_UNAUTHENTICATED=true`, and see `/dicta/health` and `/dicta/js/index.js`
  answer `200`. A build without the argument fails.
