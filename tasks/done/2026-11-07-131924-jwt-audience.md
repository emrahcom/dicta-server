# JWT audience

Add `JWT_AUDIENCE`, as `architecture.md` (Authentication, Configuration) says:
when it is set, a token whose `aud` is not that value, and is not a list that
holds it, is invalid and the connection closes with `4001`; when it is not set,
`aud` is not checked. `docs/settings.md` describes it in simple English.

Tests: with `JWT_AUDIENCE` set, a token with that `aud`, and one with a list
that holds it, connects; a token with another `aud` or none closes with `4001`.
Without it, a token with any `aud` or none connects.
