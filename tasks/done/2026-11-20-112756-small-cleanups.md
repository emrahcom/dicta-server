# Small cleanups

Code quality fixes from the review of 2026-11-20, with no change in behaviour
and no move between files. The larger moves come in a later task.

- `src/providers/provider.ts`: one open time limit for every provider, next to
  `MAX_PROVIDER_BUFFER_BYTES` (`architecture.md`, Providers). Deepgram and
  Mistral use it in place of their own copies, and their messages build the "10
  seconds" from it.
- `src/providers/index.ts`: the provider factory type is named once.
- `src/providers/mistral.ts`: `describeError` uses if/else in place of a nested
  ternary.
- `src/providers/deepgram.ts`: the retry without the region code has one
  positive condition.
- `src/server.ts`:
  - one helper closes a socket only when it is open, in place of four copies;
  - one `message` listener restarts the idle timer and counts the audio;
  - the open-socket test that cannot fail goes;
  - `"jwtSecret" in auth` is tested once;
  - the comment on the unhandled promise sits above the call it explains.
- One helper turns a thrown value into its message, used in `index.ts`,
  `server.ts` and the providers.
- `src/index.ts`: the upper bound of the connection age is named so that it is
  not taken for the setting itself.
- `test/live/transcribe.ts`: `UTTERANCES` and `FIXTURE_WORDS` are no longer
  exported.
- Comments over 80 characters are rewrapped.

Tests: the existing tests pass unchanged.

Check: `npm run check`, `npm run lint` and `npm run test` pass.
