# Test cleanups

Test fixes from the code quality review of 2026-11-20. The tests check the same
behaviour as before, with less repetition, in the file a reader would look in.

- `test/helpers.ts`, new: the helpers of `test/server.test.ts`, such as starting
  the server, signing a token, opening a connection, reading the next message as
  JSON, waiting for a close, the fake provider, and `wait` and `tick` in place
  of the inline timeouts. `start` also returns the HTTP address, so no test
  rewrites the WebSocket one. A raw upgrade request takes its extra headers as
  options, and opening a connection with a fake provider takes the connection
  age, so no test copies them.
- `test/server.test.ts` is split by concern into files a reader would look for,
  such as tokens, connections and utterances, and HTTP. The audience rejections
  become rows of the rejection table, and the broken `JSON.stringify` is one
  helper.
- `test/providers/deepgram.test.ts`: one small helper reads the query of a
  request.

Check: `npm run check`, `npm run lint` and `npm run test` pass, with no checked
behaviour lost.
