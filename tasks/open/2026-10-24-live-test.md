# Live test

An opt-in test against the real Mistral API, to catch changes on Mistral's side.

- About 5 seconds of English speech from a LibriVox (public domain) recording as
  `test/fixtures/speech-en.wav`, 16 kHz mono PCM16. Its source in
  `test/fixtures/README.md`.
- `test/live/mistral.live.ts`: start the server with `PROVIDER=mistral`, stream
  the clip in 100 ms frames and stop. Expect `ready`, at least one final, and a
  few known words of the clip in the finals.
- Skipped with a clear message when `MISTRAL_API_KEY` is not set.
- `npm run test:live` runs it. `npm run test` does not.
- Mention it in the verification commands of `CLAUDE.md` as optional.
