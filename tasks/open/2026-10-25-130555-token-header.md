# Token header

Read the token from the `Sec-WebSocket-Protocol` header instead of the URL, per
`contract-protocol.md` (Connection).

- Take the JWT from the entry after `dicta` in `Sec-WebSocket-Protocol`, and
  answer with `dicta` when the client offers it. A `token` in the URL is no
  longer read.
- Without `dicta` and a JWT, the token is missing: close with `4001`, unless
  unauthenticated mode is on.
- Update the tests and the live helper to send the token in the header. Add a
  test that a token in the URL is not accepted.
