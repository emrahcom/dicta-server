# End message

Let the client finish an utterance with `end`, per `contract-protocol.md`
(Client to server) and `architecture.md` (Providers).

- Add "finish an utterance" to the provider stream interface: Mistral sends
  `input_audio.flush`, Deepgram sends `Finalize`, the stub sends its final. The
  1 second timer uses the same step.
- Server: a text frame `{"type":"end"}` finishes the utterance. Other text
  frames stay ignored, also when they are not valid JSON.
- Tests for the server and each provider. The live helper sends `end` after the
  clip.
