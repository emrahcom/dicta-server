# Live utterances

Check one final per finished utterance against the real APIs, per
`contract-protocol.md` (Client to server, Server to client).

- The live helper runs several utterances on one connection, each ended with
  `end`: the clip twice, then silence only, then `end` with no audio.
- Each utterance gets exactly one final: the clip's words for the clip, empty
  text for the others. No error and no close the client did not start.
