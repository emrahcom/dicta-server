# Image workflow

Add `.github/workflows/image.yml`, per `architecture.md` (Image workflow, Docker
image).

- Triggers: `release` (`published`) and `workflow_dispatch`. Permissions:
  `contents: read`, `packages: write`.
- It finds the `dicta-server` tag to build (the release's tag, or the latest
  release's tag when run by hand) and the latest `dicta-js` release tag with
  `gh`, checks out the `dicta-server` tag, builds the image with
  `DICTA_JS_VERSION` and the source label, and pushes it as the version and
  `latest` to `ghcr.io/emrahcom/dicta-server`.
- Docs: `docs/releasing.md` (Docker image) tells that the package must be made
  public once after the first push, and how to start the workflow by hand.
  `docs/deployment.md` (Docker) tells how to pull the image.
- Check: the workflow file is valid YAML. It can only run on GitHub, so the user
  runs it there.
